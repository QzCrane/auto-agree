# Security policy

Do not include account credentials, session tokens, private URLs, or personally identifying login data in bug reports.

For ordinary correctness bugs, open a minimal reproducible issue with public HTML/DOM structure where possible. For a vulnerability that could cause unauthorized consequential consent or expose sensitive data, use GitHub's private security-reporting mechanism when available rather than publishing exploit details in a public issue.

The project intentionally stores only bounded local structural learning metadata; it does not transmit browsing or consent data to a server.
