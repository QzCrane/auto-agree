## Production changes

### Worker document lifecycle gate

Explicit non-active `MessageSender.documentLifecycle` states (`prerender`, `cached`, `pending_deletion`) are synchronously rejected before profile mutation or dynamic script injection. Probe/Gate/Engine lifecycle guards remain in place.

### Restart-safe handoff

Probe→Gate and Gate→Engine messages have bounded retry delays after a runtime channel failure. Profile GET/PUT/invalidation messages are replayed up to two times; their Worker operations are idempotent under duplicate delivery. Persistent profile state remains in `chrome.storage`.

### Update rehydration

`runtime.onInstalled(reason=update)` records a session marker and performs a bounded bootstrap sweep across existing tabs/frames. A worker restarted before completion sees the marker and resumes. No `tabs` permission is added.

### Fair/stale-aware injection scheduler

The existing 4-global/2-per-tab hard limits remain. v8 adds bounded queue aging, tie rotation across tabs, a 15-second stale ceiling, and priority admission that permits a newly queued Engine request to replace younger lower-priority Gate backlog when the hard queue cap is full.

### Native validity causality

A disabled proceed action contributes agreement-gating evidence only when credential controls are both non-empty and natively valid. `ValidityState.valid` is inspected without invoking `checkValidity()`.

### Weak handoff seed ownership

Cross-tier seed elements are carried through `WeakRef` and consumed/cleared by the next tier. v8 Gate/Engine still read the old v7 strong `.seed` field for update compatibility.
